5. Dashboard

Аналитика по вам и семье. Цифры ведут в Tasks.

Вкладки My и Family

  • My — ваши личные задачи (вам / от вас)
  • Family — общие семейные (нужна группа)

Плитки Overview

Четыре плитки: Total, Open, Done, Overdue.

1
Счётчик > 0 Тап → Tasks с подходящими фильтрами для этой вкладки.
2
Счётчик = 0 Только snackbar, например No overdue tasks yet — Tasks не открывается.

Другие тапы

  • Completion → Tasks (тот же scope вкладки)
  • By status → этот статус на Tasks
  • For me / By me → соответствующие view-фильтры
  • Family progress → семейные задачи
  • See all N overdue → все просроченные
  • Строка overdue → детали задачи
Сброс «режима Dashboard»: на Tasks смена view-pill или status-menu убирает специальный фильтр с дашборда — снова обычные фильтры.

Сравнение недель

Под completion: например Done this week: 5 (↑2 vs last week) (неделя с понедельника).

Member activity (Family)

Open / Done / Created по участникам. Если open ≥ 3 — badge Busy.

Share family summary (итерация 12)

На вкладке Family кнопка Share family summary открывает системный share с текстом вида Family closed 12/15 tasks · 2 overdue.
