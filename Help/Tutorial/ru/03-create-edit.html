3. Создание и правка задач

Форма новой задачи, типы, исполнитель, дедлайн, напоминания.

Открыть форму

1
Нажмите зелёную кнопку + Справа внизу на экране Tasks.

Поля

  • Title * — обязательно
  • Description — по желанию
  • Priority — Lowest … Critical
  • Status — To Do / In Progress / Done
  • Deadline — дата и время, опционально

Personal и Family

Если вы в семейной группе:

  • Personal — можно назначить участнику (Assign to)
  • Family — видят все в семье (без одного assignee)
Подсказка под переключателем: Family — «видны всей семье»; Personal — «назначена одному человеку».

При первом назначении другому — разовый tip: они увидят задачу во For me.

Напоминания

  • No reminder
  • In 1 hour
  • In 1 day

Повтор (Repeat)

  • No repeat
  • Daily — после Done: копия с deadline +1 день
  • Weekly — после Done: копия с deadline +7 дней
  • Monthly — после Done: копия с deadline +1 календарный месяц (день обрезается до конца месяца)

Те же title, assignee, priority, тип Personal/Family. Статус новой — To Do. В detail виден label повтора. При edit можно сменить или выключить.

Заметка: Undo Done не удаляет уже созданную следующую копию.
Только локально: срабатывают на этом устройстве при разрешённых уведомлениях. Done отменяет reminder.

Карточка задачи

2
Тап по строке Открывается Task details.
  • Карандаш — редактирование (если вы создатель)
  • Быстрый статус — при Done есть Undo
  • Корзина — удаление с подтверждением
Права: исполнитель обычно меняет только статус. В деталях, если нельзя edit — баннер Only the creator can edit this task.
