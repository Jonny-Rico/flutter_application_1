Итерация 15 — подробно

  • Settings → Sign-in methods
  • Email: Link Google
  • Google: Add email and password
  • Тот же uid; чужие уже занятые аккаунты не сливаются

Итерация 14 — подробно

  • Письмо verification после Create account
  • Create/join семьи заблокированы, пока не открыта ссылка
  • Settings / Family: Resend + I have verified
  • Личные задачи доступны сразу

Итерация 13 — подробно

  • Email — Create account (имя, email, пароль ≥ 8) или Sign in with email
  • Forgot password — письмо со ссылкой от Firebase
  • Google — по-прежнему доступен; одна семья для обоих типов
  • Дальше — link Google ↔ email (15)

Итерация 12 — подробно

  • Repeat — No repeat / Daily / Weekly / Monthly; следующая копия после Done
  • Share family summary — кнопка на Family Dashboard → системный share
  • Skeletons — плейсхолдеры при загрузке Tasks и Dashboard
  • Haptics — лёгкая вибрация на Done; средняя на Delete
  • Spacing / contrast — единый ритм секций; overdue red чуть ярче
  • Login — Aurora Home (вариант K), крупный лого по центру
  • App lock — PIN + биометрия (Settings); lock при открытии / фоне

Итерация 11 — подробно

  • Invite TTL — код 7 дней; expired join отклоняется
  • Regenerate — новый код отзывает старые pending; UI показывает expires
  • Weekly — в форме No repeat / Weekly; после Done — копия с deadline +7 дней
  • Detail — «Weekly — next copy after Done»

Итерация 10 — подробно

  • После create group — разовый диалог: Invite member / Not now
  • После join — welcome: OK / Go to Tasks / Create task
  • Первое назначение другому — tip: увидят во For me
  • Форма задачи — подсказка под Personal/Family
  • Детали задачи — баннер, если нельзя edit (only creator)

См. также 4. Семья и 3. Создание и правка.

Итерация 9 — подробно

Полное описание: 2. Список задач.

  • Сортировка — overdue → ближайший deadline → выше priority → недавно обновлённые
  • Поиск — 🔍 в AppBar; title + description; clear / close; «No matches»
  • Long-press — sheet: Mark done (с Undo), Edit, Delete (по правам)
  • Аватар assignee — буква/фото на personal; метка Family на family-задачах
