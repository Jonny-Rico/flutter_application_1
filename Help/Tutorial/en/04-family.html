4. Family group

Create a group, invite members, assign personal tasks, share Family tasks.

Email accounts: create or join a family only after you open the verification link and tap I have verified. Google sign-in is usually already verified. Personal tasks work without verification.

Open Family

1
Bottom nav → Family Screen title: Family Group.

Create a group (owner)

  1. If you have no group, use create flow and enter a group name.
  2. You become the owner.
  3. Member counter shows e.g. 1/10.
  4. Each invite code is for one person. Generate a new code for the next member.

Invite someone

2
Tap the invite icon Top-right (owner only) → invite code screen.

Share the code with another Google user who has the app.

  • Codes expire in 7 days (shown under the code)
  • Regenerate code creates a new one and revokes the previous pending code
  • Expired or revoked codes cannot be used to join

Join with a code

3
On the second account: Family → join Enter the code. Invalid or expired codes show an error.

Members

  • Owner can remove members
  • Member can leave the group
  • Owner can dissolve the group

How tasks relate to family

  • Personal + Assign to — another member sees it under For me
  • Family type — everyone in the group can see and update status
  • View filters For me / By me / Family appear on Tasks only when you are in a group

Onboarding (Iteration 10)

4
After you create a group One-time dialog: Invite member or Not now. Shown only once per account.
5
After you join with a code Welcome dialog: check For me, or go to Tasks / Create task.

When you first assign a Personal task to someone else, a tip explains they will see it under For me.

Tip: Use two Google accounts (or two emulators) to test invite + assignment.
