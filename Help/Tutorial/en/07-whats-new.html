What’s new (by iteration)

Update this page after every product iteration so the guide stays complete.

  • 1–4 — Google sign-in, tasks CRUD, family groups, invites, permissions, filters
  • 4.5+ — Compact list, swipe Done/Delete, filter persistence, bugfixes
  • 5 — Local reminders (1 hour / 1 day), new-task local alerts, tap notification → detail
  • UI polish — Login & Tasks speed list; full-width filter pills with badges
  • 6 — Dashboard analytics; My / Family tabs
  • 7 — Reset filters empty state, status chip in AppBar, Overdue pill, Undo Done
  • 8 — Dashboard taps → Tasks; snackbar when count is 0; week comparison; Busy members; See all overdue
  • 9 — List power tools (see below)
  • 10 — Family onboarding + clarity (see below)
  • 11 — Invite expiry/regenerate + weekly recurrence (see below)
  • 12 — Daily/Monthly repeat, share family summary, skeletons, haptics, spacing (see below)
  • 13 — Email register / sign-in / reset + display name (see below)
  • 14 — Hard email verification for Family (see below)
  • 15 — Link Google ↔ email on the same account (see below)
  • 16 — Edit display name in Settings

Iteration 15 — details

  • Settings → Sign-in methods
  • Email user: Link Google
  • Google user: Add email and password
  • Same uid; already-used accounts cannot be merged here

Iteration 14 — details

  • Verification email after Create account
  • Family create/join locked until the link is confirmed
  • Settings / Family: Resend + I have verified
  • Personal tasks stay available immediately

Iteration 13 — details

  • Email account — Create account (name, email, password ≥ 8) or Sign in with email
  • Forgot password — Firebase sends a reset link
  • Google still works — same family space for both account types
  • 14 — Hard email verification: Family locked until the inbox link is confirmed

Iteration 12 — details

  • Repeat — No repeat / Daily / Weekly / Monthly; next copy on Done (+1 day / +7 days / +1 month)
  • Share family summary — Family dashboard button opens system share sheet
  • Skeletons — Tasks list and Dashboard loading placeholders
  • Haptics — light feedback on Done; medium on Delete confirm
  • Spacing / contrast — section rhythm tokens; overdue red slightly brighter on dark UI
  • Login — Aurora Home (variant K) with large centered app icon
  • App lock — optional PIN + biometrics (Settings); locks on open / background

Iteration 11 — details

  • Invite TTL — codes expire in 7 days; expired join is rejected
  • Regenerate — new code revokes previous pending codes; UI shows expiry time
  • Weekly repeat — form: No repeat / Weekly; on Done, next task with deadline +7 days
  • Detail — shows “Weekly — next copy after Done”

Iteration 10 — details

  • After create group — one-time dialog: Invite member / Not now
  • After join — welcome: OK / Go to Tasks / Create task
  • First assign to someone else — tip: they’ll see it under For me
  • Task form — help under Personal/Family toggle
  • Task detail — banner when you cannot edit (only creator can)

Also see 4. Family and 3. Create & edit.

Iteration 9 — details

Documented fully in 2. Tasks list.

  • Search — AppBar 🔍; title + description; clear / close; “No matches”
  • Long-press — bottom sheet: Mark done (with Undo), Edit, Delete (permissions apply)
  • Assignee avatar — initial/photo on personal rows; Family label on family tasks
