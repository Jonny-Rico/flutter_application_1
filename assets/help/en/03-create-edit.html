3. Create & edit tasks

New task form, types, assignee, deadline, and reminders.

Open the form

1
Tap the green + button Bottom-right on the Tasks screen.

Required fields

  • Title * — required; empty save shows an error snackbar
  • Description — optional
  • Priority — Lowest … Critical
  • Status — To Do / In Progress / Done
  • Deadline — optional date & time

Personal vs Family

If you are in a family group:

  • Personal — assign to a member (dropdown Assign to)
  • Family — visible to everyone in the group (no single assignee)
Help under the toggle: Family → “Family tasks are visible to everyone in your family.” Personal → “Personal tasks are assigned to one person.”

First time you assign a Personal task to someone else, a one-time tip explains they will see it under For me.

Reminders

On create/edit:

  • No reminder
  • In 1 hour
  • In 1 day

Repeat

  • No repeat
  • Daily — on Done, new copy with deadline +1 day
  • Weekly — on Done, new copy with deadline +7 days
  • Monthly — on Done, new copy with deadline +1 calendar month (day clamped to month end)

Same title, assignee, priority, and Family/Personal type. New task status is To Do. Detail shows the repeat label. You can change or turn off repeat when editing.

Note: If you Undo Done after a repeating task, the already-created next copy is not deleted.
Local only: Reminders fire on this device after you allow notifications. Completing a task cancels its reminder.

Edit & detail

2
Tap a task row Opens Task details.
  • Pencil → edit (if you are the creator)
  • Quick status segments — changing to Done offers Undo
  • Trash → delete with confirm (if allowed)
Permissions: Assignees can usually change status but not edit title/delete. On task detail, if you cannot edit, you see: Only the creator can edit this task.
