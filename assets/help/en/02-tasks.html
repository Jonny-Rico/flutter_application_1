2. Tasks list

Browse, filter, search, complete, and delete tasks. Includes Iteration 9 power tools: sort, search, long-press menu, assignee avatars.

View filters (when you have a family)

Four equal pills across the top:

  • For me — assigned to you
  • By me — you created for someone else
  • Family — shared family tasks
  • All — everything

The number in the circle is the count for that filter.

Status filter

1
Tap the chip in the AppBar Shows To Do ▾, All statuses ▾, etc. Also shows Open / Overdue after Dashboard taps.

Pick To Do, In Progress, Done, or All statuses.

Search (Iteration 9)

2
Tap the search icon (🔍) in the AppBar A field appears under the title: search by title or description.
  • Clear text with × in the field
  • Close search with the AppBar close icon — query is cleared
  • No matches → No matches + Clear search

Complete a task

3
Checkbox Tap the circle on the left of a row.
4
Swipe right Green “done” action appears.
Undo: After Done you get a snackbar Task marked as done with Undo for about 5 seconds. Reminder times are not restored on Undo.

Long-press menu (Iteration 9)

5
Press and hold a task row A bottom sheet opens with actions you are allowed to use.
  • Mark done — if you can change status (and task is not already Done); uses Undo
  • Edit — if you can edit (usually the creator)
  • Delete — if you can delete; asks for confirmation

If nothing is allowed, a short snackbar says so.

Delete (swipe)

Swipe left → confirm dialog. Only if you have permission (usually the creator). Same as Delete in the long-press menu.

Sort order (Iteration 9)

The list is always sorted automatically (no setting to change):

  1. Overdue open tasks first
  2. Then soonest deadline (tasks without a date go later)
  3. Then higher priority (Critical before Low)
  4. Then recently updated

Overdue badge

Open tasks with a past deadline show a red date and an Overdue pill. Done tasks never show Overdue.

Assignee avatar (Iteration 9)

  • Personal tasks — small circle with the assignee’s initial (or photo if available). Long-press the avatar isn’t required; tooltip shows the name.
  • Family tasks — label Family instead of an avatar

Empty list

  • No tasks at all → button New task
  • Filters hide everything → primary Reset filters, then New task
  • Search has no hits → No matches + Clear search

Reset restores defaults: with “Remember filters” on → For me + To Do; off → All + All statuses. It also clears search and temporary Dashboard filters.

Scrollbar

If the list is long, a scrollbar appears on the right for every filter.
