5. Dashboard

Analytics for you and your family. Numbers open Tasks when useful.

Tabs: My and Family

  • My — your personal tasks (for you or created by you)
  • Family — shared family tasks (requires a group)

Overview tiles

Four tiles: Total, Open, Done, Overdue.

1
Count greater than 0 Tap → opens Tasks with matching filters for this tab.
2
Count is 0 Snackbar only, e.g. No overdue tasks yet — Tasks is not opened.

Other tappable areas

  • Completion card → Tasks (same scope as the tab)
  • By status rows → that status on Tasks
  • For me / By me (My workload) → those view filters
  • Family progress → Family tasks on Tasks
  • See all N overdue → full overdue list on Tasks
  • Overdue rows → open task detail
Leaving dashboard filters: On Tasks, changing a view pill or the status menu clears the special Dashboard filter mode so normal filters apply again.

Week comparison

Under completion: e.g. Done this week: 5 (↑2 vs last week) (week starts Monday).

Member activity (Family)

Shows open / done / created per member. If open ≥ 3, a Busy badge appears.

Share family summary (Iteration 12)

On the Family tab, under Family progress, tap Share family summary to open the system share sheet with text like Family closed 12/15 tasks · 2 overdue.
