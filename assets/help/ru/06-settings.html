6. Настройки и уведомления

Профиль, память фильтров, локальные уведомления, выход.

Профиль

Имя, email и фото (если есть). Карандаш — сменить имя (минимум 2 символа). Обновляется Auth, профиль и список участников семьи.

Remember task filters

  • Вкл. — сохраняет view + status; часто For me + To Do
  • Выкл. — при входе All + All statuses

Haptic feedback

  • Вкл. (по умолчанию) — лёгкая вибрация на Done; средняя на Delete
  • Выкл. — без вибрации для этих действий

Сохраняется на аккаунт. При включении — короткий импульс для проверки.

App lock

  • Вкл. — 4-значный PIN; опционально биометрия
  • Разблокировка при открытии приложения и после ухода в фон
  • Unlock with biometrics — выкл. = только PIN
  • Change PIN — сначала подтверждение
  • Выключение lock — biometrics или PIN

Google sign-in не меняется. App lock защищает доступ на этом устройстве.

Локальные алерты: о новой задаче — после синхронизации на этом устройстве (открытие / логин приложения). Это не полноценный серверный push, пока приложение никогда не запускалось.

Чужая Family-задача или Personal «на вас» → New task for you / New family task. Тап открывает детали.

Sign-in methods

Один аккаунт может использовать и Google, и email (тот же uid).

  • Link у Google — привязать Google (если регистрировались по email)
  • Add у Email and password — задать email + пароль (если входили через Google)

Если этот Google/email уже у другого пользователя FamilyTasks — связать нельзя. Войдите тем аккаунтом.

Notification permission

Отдельный пункт — снова запросить разрешение Android.
