2. Список задач

Просмотр, фильтры, поиск, выполнение и удаление. Включает инструменты итерации 9: сортировка, поиск, long-press, аватары assignee.

Фильтры вида (если есть семья)

Четыре равные кнопки сверху:

  • For me — назначены вам
  • By me — вы назначили другому
  • Family — общие семейные задачи
  • All — все

Цифра в кружке — количество задач в этой вкладке.

Фильтр статуса

1
Нажмите chip в AppBar Например To Do ▾ или All statuses ▾. После тапов с Dashboard также бывают Open / Overdue.

Выберите To Do, In Progress, Done или All statuses.

Поиск (итерация 9)

2
Иконка поиска (🔍) в AppBar Под заголовком появляется поле: поиск по title и description.
  • Очистить текст — × в поле
  • Закрыть поиск — иконка закрытия в AppBar (запрос сбрасывается)
  • Нет совпадений → No matches + Clear search

Завершить задачу

3
Checkbox Тап по кружку слева в строке.
4
Свайп вправо Зелёная зона «Done».
Undo: после Done — snackbar Task marked as done и кнопка Undo (~5 сек). Напоминание после Undo не восстанавливается.

Long-press меню (итерация 9)

5
Удержите строку задачи Снизу откроется sheet с доступными вам действиями.
  • Mark done — если можно менять статус (и задача ещё не Done); с Undo
  • Edit — если можно редактировать (обычно создатель)
  • Delete — если можно удалять; с подтверждением

Если действий нет — короткий snackbar.

Удаление (свайп)

Свайп влево → диалог подтверждения. Обычно только создатель. То же, что Delete в long-press.

Сортировка (итерация 9)

Список всегда сортируется автоматически (настройки нет):

  1. Сначала Overdue (открытые просроченные)
  2. Затем ближайший deadline (без даты — ниже)
  3. Затем выше priority (Critical выше Low)
  4. Затем недавно обновлённые

Бейдж Overdue

Открытые задачи с прошедшим дедлайном: красная дата и pill Overdue. У Done overdue не показывается.

Аватар assignee (итерация 9)

  • Personal — кружок с буквой имени (или фото, если есть)
  • Family — метка Family вместо аватара

Пустой список

  • Задач нет совсем → кнопка New task
  • Фильтры всё скрыли → сначала Reset filters, затем New task
  • Поиск ничего не нашёл → No matches + Clear search

Reset: при «Remember filters» вкл. → For me + To Do; выкл. → All + All statuses. Также сбрасывает поиск и временные фильтры с Dashboard.

Полоса прокрутки

При длинном списке справа виден scrollbar на всех вкладках.
